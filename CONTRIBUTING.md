# Contributing

Thank you for your interest and kindness!

This repository is maintained as a **spare-time personal project**. The maintainer's time is limited; issues, requests and pull requests may not receive a reply or a merge, and no response time is promised. Please keep this in mind when opening an issue.

If reporting a bug, include the Home Assistant Core version, installation type, Reolink model, which output mode failed, sanitized automation traces, the failing action and how to reproduce it. **Never include** real IP addresses, URLs with credentials, API keys, camera passwords, unique device identifiers or private footage.

For code changes, keep modules small, follow established paths and input names, add offline tests when practical, and explain any change to backward-compatible defaults. A working end-to-end test is valuable, but cannot be run by GitHub Actions against a real camera.

Please be considerate of fellow users and maintainers. This is provided as-is, not as a hosted support service.
