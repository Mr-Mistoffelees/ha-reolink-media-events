# Changelog

## 1.0.0 — Initial public packaging (2026-10-13)

- Event-based Reolink media blueprint, ntfy and Immich branches.
- Clear/Fluent selection independently for ntfy and Immich.
- Snapshot and video sources, multi-lens camera mapping via RTSP channel configuration.
- FFmpeg recording with stream copy and audio, file verification, per-run media paths, opt-in cleanup and diagnostics.
- Manual installation guide, examples, offline tests and contribution/security information.

The first public release is based on an end-to-end configuration tested with Home Assistant Container 2026.10.1. Offline CI does **not** assert that external services or physical cameras are reachable.
